# 暗房 · Darkroom

一个零依赖的生成艺术工作台。选一种算法，拧几个参数，定影保存成 PNG。

整个项目没有构建步骤、没有第三方库、没有网络请求——所有代码都是原生的 HTML / CSS / JavaScript。

## 打开方式

直接双击 `index.html` 就能用（现代浏览器均可）。

如果浏览器拦下了保存图片的下载，用任意静态服务器打开即可：

```bash
python3 -m http.server 8000
# 然后访问 http://127.0.0.1:8000
```

## 六种算法

| # | 名称 | 原理 | 画面上的反应 |
|---|------|------|--------------|
| 01 | 流场粒子 | 粒子沿着柏林噪声风场游走，拖尾堆积 | 鼠标推开粒子，点击播撒一团 |
| 02 | 群体游动 | 分离、对齐、聚合三条规则涌现出群体运动 | 鼠标是看不见的捕食者，群体绕开它 |
| 03 | 圆堆积 | 贪心算法在画布上密铺圆点 | 在空白处点击，从指尖长出一簇圆 |
| 04 | 递归分形 | 递归树，每根枝条的角度由位置噪声决定 | 点击换一棵树；风调到 0 就静止 |
| 05 | 特鲁谢瓷砖 | 随机朝向的四分之一圆弧接成迷宫织物 | 点击重新洗牌；网格越小越细密 |
| 06 | 谐波玫瑰 | 错开相位的玫瑰线叠加成光 | 鼠标让花心偏向指尖 |

## 操作

- **药方**（顶栏输入框）：同一个编号必然生成同一张图。改完按回车重新生成。
- **换药方**：随机换一个编号。
- **定影保存**：按 2 倍分辨率重绘当前画面并下载 PNG，同时右下角胶片条会多一张缩略图（带显影动画），点缩略图可以看大图。
- **显影参数**：每种算法 5–7 个滑杆，实时生效。标注为结构性的参数（网格边长、最小半径等）改动后会重新排布，其余即时变化。
- **相纸**：四套配色——安全灯、深海、苔原、夜樱。
- **随机参数 / 恢复默认**：在保留药方的前提下换一副参数。

快捷键：`1`–`6` 切换算法，`空格` 暂停/继续，`R` 换药方，`S` 定影保存，`P` 换相纸，`H` 隐藏界面，`F` 全屏，`C` 重新曝光。

## 它是怎么搭起来的

```
index.html            页面骨架
css/style.css         视觉系统（色彩、字体、布局）
js/rng.js             种子随机数 + 3D 柏林噪声 + 文本药方散列
js/sketch-*.js        六种算法，各自独立注册
js/app.js             界面装配、动画循环、定影导出
```

每种算法是一个注册到 `Darkroom.sketches` 上的对象，接口只有四样：

```js
{
  id, name, desc, hint,          // 身份与说明
  params: [{ key, label, min, max, step, def }],   // 参数定义
  structural: ['cell'],          // 改动后需要重新排布的参数
  settle: 420,                   // 导出时要预演的帧数
  init(s), frame(s, dt), adjust(s, key), pointer(s, x, y)
}
```

`s` 是状态对象，带着种子随机数、噪声、参数、配色、尺寸和画布上下文。想加第七种算法，新建一个 `js/sketch-xxx.js`、按上面的格式注册、在 `index.html` 里加一行 script 标签、再把 id 填进 `app.js` 的 `ORDER` 数组即可。

### 两个值得留意的实现细节

**确定性的来源。** 药方文本经 FNV-1a 散列成一个整数，喂给 mulberry32 生成随机数流，再用这条流洗牌出噪声的置换表。所以同一个药方 + 同一套参数，在任何机器、任何时刻都得到同一张图——这也是"换药方"这个比喻成立的原因。

**`arc()` 会偷偷连线。** Canvas 的 `ctx.arc()` 在路径上已有当前点时，会先拉一条直线到弧的起点。批量把很多个弧画进同一个 path 再统一 stroke，弧与弧之间会被直线串成乱麻（特鲁谢瓷砖最初就是这样）。所以每个弧之前都要先 `moveTo()` 到弧的起点。

## 设计笔记

**为什么是暗房。** 生成艺术的过程和冲印照片同构：一套随机种子是药方，拧参数是显影，保存是定影。界面语言跟着这个比喻走，但控件标签保持直白——"定影保存"就是保存，不会为了比喻牺牲清晰。

**色彩。** 暖调近黑 `#17140F` 打底，安全灯的琥珀 `#E8862E` 只出现在真正要动手的地方：滑杆、选中的算法、定影按钮、还有左上角那盏会呼吸的指示灯。画布才是主角，界面其余部分退到发丝线后面。

**字体。** 宋体做作品名和当前算法名，等宽字体承载所有读数——参数面板天生是数字界面，等宽字让纵向的一列小数对齐。全部使用系统字体，不引入任何网络字体。

**签名元素。** 定影之后，右下角胶片条里那张图是"显"出来的：从模糊、低对比、过亮的状态过渡到清晰，像相纸在显影液里浮出影像。

## 兼容性

- 桌面与手机竖屏均可用（面板在窄屏变成底部可滚动区域）
- 支持键盘操作与焦点可见样式
- 尊重系统的"减弱动效"设置：检测到时会自动暂停动画并提示
- 画布按 devicePixelRatio 渲染，导出固定 2 倍分辨率
